# Deliverables

> Academic prototype for Ivey Online coursework. Not affiliated with or representative of the Financial Services Regulatory Authority of Ontario (FSRA). All insurer submissions and precedent records are fictional.

| Folder | Contents |
|---|---|
| [`report/`](report/) | The written report: `Simrule-report.pdf` (submission) and `Simrule-report.docx`. Built by `npm run report`. |
| [`architecture/`](architecture/) | One-page solution architecture: SVG, PNG, PDF and `architecture.md`. Built by `npm run architecture`. |
| [`demo/`](demo/) | `screen-recording-script.md` (backup walkthrough), sample filings for the Intake screen, screenshots of every main screen, and the accessibility (axe) report. |
| [`process/`](process/) | How it was built and checked: `prompt-log.md` (every prompt and iteration), `consistency-audit.md`, `spot-check.md`, and `VERIFY.md` (legal references still to confirm against official sources). |

The live app is at https://jevwithwind.github.io/simrule/. The optional chatbot and avatar video were not built.
